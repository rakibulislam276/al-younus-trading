# AL YOUNUS Trading and Services — Website Starter

A responsive Next.js starter storefront for hygiene, cleaning and sanitation supplies, with WhatsApp enquiry links and a visual admin dashboard preview.

## Run locally

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Current status

- Responsive storefront and sample product cards: included.
- WhatsApp enquiry links: included; confirm the business number before launch.
- Admin dashboard: visual preview only, not secured or database-connected.
- Product prices: enquiry-based placeholders.
- Database, authentication, live CRUD, image upload, inventory, customer CRM and orders: not implemented yet.

Do not use the admin preview for real customer data until authentication and backend storage are implemented.
